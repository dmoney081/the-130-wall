Setup in about 15 minutes

  1. Upload the files to a new GitHub repo.
  2. Edit config.json: goal, deadline, Ko-fi link, grid size, prices.
  3. Replace the lines marked EDIT ME in index.html with your own words.
  4. Turn on GitHub Pages. Share the link.

You need a free GitHub account and a Ko-fi page with PayPal or Stripe connected. Python is optional: it powers the helper script, but you can edit board.json by hand instead.
